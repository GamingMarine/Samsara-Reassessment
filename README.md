# Samsara Reassessment
Samsara Reassessment is a personal fork of [Samsara Reincarnation](https://github.com/Samsara-Reincarnation/Samsara-Reincarnation), a Doom mod which implements weapon sets from numerous other Doom clones/old first-person shooters. This fork does not add any major features to the mod (or at least that's not the focus); Instead, Reassessment mainly centers around improving accuracy to the represented games' source material. For a detailed list of what's different from upstream Samsara, check out the included [ReassessmentChanges.txt](ReassessmentChanges.txt) file.

## Disclaimer
Samsara Reassessment is my own personal fork, and is not affiliated with the Reincarnation project and/or team. However, I am open to any of Reassessment's changes being officially backported upstream.
