# Samsara Reassessment
Samsara Reassessment is a fork of [Samsara Reincarnation](https://github.com/Samsara-Reincarnation/Samsara-Reincarnation), a Doom mod which implements weapon sets from numerous other Doom clones/old first-person shooters. This fork does not add any major features to the mod (or at least that's not the focus); Instead, Reassessment mainly centers around improving accuracy to the represented games' source material. For a detailed list of what's different from upstream Samsara, check out the included [ReassessmentChanges.txt](ReassessmentChanges.txt) file.

## Disclaimers
1: Samsara Reassessment is primarily tested on its own, and has not been extensively tested with the Remixer addon. If you plan on playing this fork with Remixer, keep in mind that you might come across bugs that may not be present when playing with upstream Samsara. Nonetheless, feel free to report any issues to me in that regard.
 
2: Samsara Reassessment is my own personal fork, and is not affiliated with the Reincarnation project and/or team. However, I am open to any of Reassessment's changes being officially backported upstream.
